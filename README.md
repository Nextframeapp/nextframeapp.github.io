# Central Legal NextFrame

Site público com a Política de Privacidade, os Termos de Uso, as Regras de
Publicação, as instruções para exclusão de conta e o canal de contato do
NextFrame.

## Endereços

- `/privacy/`: Política de Privacidade
- `/terms/`: Termos de Uso
- `/publication/`: Regras de Publicação
- `/delete-account/`: Exclusão de conta
- `/contact/`: Contato

O site é estático e foi preparado para publicação pelo GitHub Pages a partir
da raiz da branch `main`.
